# MediNova Hospital Analytics Dashboard

## Overview
Developed an interactive healthcare analytics dashboard using Power BI to monitor hospital performance and key operational metrics.

## Tools Used
- Power BI
- Excel

## Key Metrics
- Monthly Revenue
- Monthly Patients
- ICU Bed Occupancy
- Recovery Days
- Emergency Cases
- Department Performance

## Features
- KPI Cards
- Slicers
- Bar Charts
- Donut Charts
- Trend Analysis

## Business Insights
- Revenue performance tracking
- Patient trend analysis
- ICU capacity monitoring
- Department-wise performance evaluation
